All 35 procedures, grouped by router. [API](/docs/integrations/api) holds the base URL, the transports and the sign-in steps.

## How to read this page

- The dot path is the client path. Over HTTP it becomes `POST /rpc/<router>/<procedure>` or `POST /api-reference/<router>/<procedure>`.
- **Public** means the procedure answers with no session. **Protected** means it needs the session cookie.
- Four procedures are public: `healthCheck`, `auth.capabilities`, `auth.accountExists` and `auth.viewer`. Every other procedure returns `UNAUTHORIZED` (401) with no session.
- The **Errors** list names only the errors of that procedure. It omits the 401.
- A date field accepts an ISO 8601 string, which the schema coerces to a date.
- Every money amount is an integer in minor units. 12.34 EUR is `1234`.

## Root procedures

### healthCheck

Public. Returns a fixed string, so a caller can probe the router itself.

**Input**: none.

**Output**: the string `"OK"`.

**Errors**: none.

### privateData

Protected. Returns a fixed string and the Better Auth user of the session.

**Input**: none.

**Output**

| Field     | Type                  | Note                                    |
| --------- | --------------------- | --------------------------------------- |
| `message` | string                | Always the literal `"This is private"`. |
| `user`    | object or `undefined` | The raw Better Auth user record.        |

**Errors**: none.

<Callout type="info">

The web app never calls `privateData`. Use it to prove that your cookie works, and nothing else.

</Callout>

## `assistant`

### assistant.getConversation

Protected. Returns the active conversation of the caller, and the model of the instance.

**Input**: none.

**Output**

| Field | Type | Note |
| --- | --- | --- |
| `conversationId` | string | The id of the active conversation. The read creates one when the caller has none. |
| `messages` | array of `{ id, parts, role }` | The stored transcript, oldest first. An archived conversation never appears. |
| `serverModel` | string or `null` | The model id of the instance, and `null` when the instance holds none. |

| Field of one message | Type | Note |
| --- | --- | --- |
| `id` | string | The row id. Pass it as `messageId` to redo that turn. |
| `parts` | array | The `UIMessage.parts` array of the AI SDK, as the stream route stored it. |
| `role` | `"user"` or `"assistant"` | The two stored roles. |

**Errors**: none.

### assistant.saveTurn

Protected. Stores one finished turn that the caller answered itself.

**Input**

| Field | Type | Required | Bounds |
| --- | --- | --- | --- |
| `answer.id` | string | yes | A UUID. It becomes the id of the answer row. |
| `answer.parts` | array | yes | At least one part. A part is a text part, a reasoning part, a step-start part or a tool part. |
| `conversationId` | string | yes | Must name the active conversation of the caller. |
| `question` | array of `{ text, type: "text" }` | yes | At least one part. Text parts only. |
| `regeneratedMessageId` | string | no | The id of the stored answer this turn replaces. |

**Output**

| Field | Type    | Note           |
| ----- | ------- | -------------- |
| `ok`  | boolean | Always `true`. |

**Errors**

- `BAD_REQUEST` (400) `Turn too large` — the question passes 8000 characters, or the answer parts pass 200000 characters as JSON.
- `NOT_FOUND` (404) `Conversation is not the active one`.
- `BAD_REQUEST` (400) `Empty answer` — no text part and no resolved tool part survived the filter.
- `TOO_MANY_REQUESTS` (429) — over 30 turns per 300 seconds. The stream route shares that allowance.

### assistant.startNewConversation

Protected. Archives the active conversation of the caller, and deletes nothing.

**Input**: none.

**Output**

| Field | Type    | Note           |
| ----- | ------- | -------------- |
| `ok`  | boolean | Always `true`. |

**Errors**: none.

## `auth`

### auth.accountExists

Public. Tells a caller whether an address already holds an account.

**Input**

| Field   | Type   | Required | Bounds                          |

| `email` | string | yes      | Must parse as an email address. |

**Output**

**Errors**

**Input**: none.

**Output**

| Field | Type | Note |

Public. Names the caller. A caller with no session gets a `guest` answer, and not a 401.

**Input**: none.

**Output**

| Field | Type | Note |

| `sessionCookieShared` | boolean | The same value `auth.capabilities` reports. |

**Errors**: none.

### bankConnection.startConnection

Protected. Opens a bank consent session and returns the URL to send the user to.

**Input**

| Field | Type | Required | Bounds |
| --- | --- | --- | --- |
| `bankCountry` | string | yes | Must match the country of the institution. |
| `institutionId` | string | yes | An `id` from `listInstitutions`. |
| `returnTo` | enum | yes | `onboarding` or `settings`. |
| `state` | string | no | Your own value. It comes back in the callback state. |

**Output**

| Field | Type   | Note                               |
| ----- | ------ | ---------------------------------- |
| `url` | string | Send the browser of the user here. |

**Errors**

- `BAD_REQUEST` (400) `Unknown bank institution`.

<Callout type="warn">

The redirect URL is `CORS_ORIGIN` plus the provider callback path, so `/callback/powens` or `/callback/enable-banking`. That target is a page route of the web app. The API server answers nothing under `/callback`, so do not proxy that path to it.

</Callout>

### budget.getTransactions

Protected. The one paged procedure. Returns transactions in a date range, with the range totals.

**Input**

| Field | Type | Required | Default | Bounds |
| --- | --- | --- | --- | --- |
| `amountMax` | number | no | — | An integer of 0 or more, in minor units. It reads the absolute amount. |
| `amountMin` | number | no | — | An integer of 0 or more, in minor units. It reads the absolute amount. |
| `categories` | array of enum | no | — | Items from the 75 [spending categories](#spending-categories). |
| `cursor` | string | no | — | A `nextCursor` from an earlier call. |
| `direction` | enum | no | — | `incoming` or `outgoing`. |
| `from` | date | yes | — | The range includes this date. |
| `groups` | array of enum | no | — | Items from the 16 [category groups](#category-groups). |
| `limit` | number | no | `50` | 1 to 100. |
| `merchants` | array of string | no | — | Company names as `budget.getMerchants` returns them. |
| `search` | string | no | — | A case-insensitive substring of the description or the counterparty name. |
| `sort` | enum | no | `date` | `date` or `amount`. |
| `to` | date | yes | — | No check against `from`. |

**Output**

| Field | Type | Note |
| --- | --- | --- |
| `nextCursor` | string or `null` | `null` on the last page. |
| `totals` | `{ incoming, outgoing }` | Over the whole filter, and not over the page. |
| `transactions` | array | The fields below. |

| Field of one transaction | Type | Note |
| --- | --- | --- |
| `amount` | number | Minor units. Negative for money out. |
| `category` | string | The effective category, so an override of the user wins. |
| `counterpartyName` | string or `null` | The counterparty name the bank sends. |
| `currency` | string | The ISO 4217 code of the transaction. |
| `date` | string | ISO 8601. |
| `derivedCategory` | string | What the pipeline resolved, before any override. |
| `description` | string | The narrative of the bank. |
| `id` | string | Pass it as `cursor` to page. |

**Errors**: none.

### budget.syncAccounts

Protected. Pulls fresh data from the bank provider, then categorises what is new.

**Input**: the whole object is optional. Send `{}` to sync every active connection.

| Field | Type | Required | Default | Bounds |
| --- | --- | --- | --- | --- |
| `connectionId` | string | no | Every active connection | Narrows the sync to one bank connection. |
| `force` | boolean | no | `false` | `true` re-reads the whole provider window. |

**Output**

| Field | Type | Note |
| --- | --- | --- |
| `categorised` | number | Transactions the run resolved. |
| `error` | string or `undefined` | Provider failures, joined together. |
| `success` | boolean | `false` when at least one connection failed. |
| `warning` | string or `undefined` | A categorisation failure. |

**Errors**: none.

<Callout type="warn">

This procedure returns HTTP 200 even when every connection failed. Read the `success` field, and not the status code.

</Callout>
